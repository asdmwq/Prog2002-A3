HOW TO OPEN THE WEBSITE
=======================

DO NOT double-click index.html. If you do, you will see an unstyled page with
"0 upcoming events" (no colours, no layout, no data) -- that is NOT the website.

This is a dynamic website. Three programs must be running before you open it:
  1. MySQL database
  2. REST API          (http://localhost:3000)
  3. Website server    (http://localhost:8080)

EASIEST WAY (one click)
-----------------------
Double-click the file on your Desktop named:
    ① START HeartBridge (double-click).cmd
(or run "start-all.cmd" in this project folder).

It will start all three programs for you, wait until the database is ready, and
then open the correct page http://localhost:8080 in your browser automatically.

WHILE USING THE SITE
--------------------
Three black/console windows stay open (MySQL, API, Website). Do not close them.
Closing them stops the website. Close them only when you are finished.

IF A WINDOW FLASHES AN ERROR
----------------------------
- "Node.js was not found": install Node.js LTS from https://nodejs.org (keep the
  default "Add to PATH" option), then run the start file again.
- If the browser still shows no data, wait ~10 seconds and refresh the page.

TO STOP EVERYTHING
------------------
Close the three console windows (MySQL / HeartBridge API / HeartBridge Website).
